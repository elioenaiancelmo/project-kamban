# 🚀 Guia Rápido - Kanban Departamento Pessoal

## ⚡ Início Rápido

### Abrir o Sistema
1. Clique duas vezes em `index.html`
2. Ou arraste o arquivo para o navegador
3. Sistema carrega instantaneamente!

## 📋 Ações Principais

### ➕ Criar Tarefa
**Botão:** "Nova Tarefa" (canto superior direito)
- Preencha título (obrigatório)
- Escolha categoria do DP
- Defina prioridade e data
- Clique em "Salvar Tarefa"

### 🔄 Mover Tarefa
**Arrastar:** Clique + Segure + Arraste
- Mova de "A Fazer" → "Em Progresso"
- Mova de "Em Progresso" → "Concluído"

### ✏️ Editar/Excluir
**Hover na tarefa:**
- 🖊️ Ícone lápis = Editar
- 🗑️ Ícone lixeira = Excluir

### 🔍 Buscar
**Barra de pesquisa:** Digite e veja resultados instantâneos

### 🎯 Filtrar
**Botão "Filtros":**
- Marque prioridades desejadas
- Marque categorias desejadas
- Clique "Aplicar Filtros"

## 🏷️ Categorias do Departamento Pessoal

### Padrão:
- ✅ Rescisão
- ✅ Folha de Pagamento
- ✅ Recibos Avulsos
- ✅ Consultar Débitos / Férias
- ✅ Consultar Saldo FGTS
- ✅ Registro

### Criar Nova Categoria:
1. No formulário, selecione "➕ Criar Nova Categoria"
2. Digite o nome (ex: "Admissões")
3. Salve a tarefa
4. Categoria fica disponível para sempre!

## 📊 Indicadores Visuais

### Prioridades:
- 🔴 **ALTA** - Vermelho
- 🟡 **MÉDIA** - Amarelo
- 🟢 **BAIXA** - Verde

### Status de Prazo:
- ✅ **NO PRAZO** - Verde (tarefa dentro do prazo)
- ⚠️ **EM ATRASO** - Vermelho piscando (passou do prazo)
- ⚪ **SEM PRAZO** - Cinza (sem data definida)
- ✔️ **CONCLUÍDA** - Verde (na coluna Concluído)

## 📈 Painel de Estatísticas

**Localização:** Lado direito da tela

### Métricas:
1. **Total de Tarefas** - Todas as tarefas no sistema
2. **Concluídas** - Tarefas finalizadas
3. **Pendentes** - Tarefas em andamento

## ⌨️ Atalhos

| Filtrar | Clique em "Filtros" |

## 🔧 Resolução de Problemas

### Tarefa não move?
- Certifique-se de clicar e segurar
- Arraste até a área da coluna
- Solte quando a área ficar destacada

### Categoria não aparece?
- Verifique se salvou a tarefa após criar
- Recarregue a página se necessário
- Categorias ficam salvas no navegador

### Filtros não funcionam?
- Clique em "Limpar Filtros" primeiro
- Selecione novamente os desejados
- Clique em "Aplicar Filtros"

## 📱 Mobile

O sistema funciona perfeitamente em celular:
- Toque para editar/excluir
- Arraste para mover (touch)
- Layout adaptado automaticamente
- Estatísticas ficam no topo

## 🎯 Casos de Uso

### Exemplo 1: Rescisão Urgente
1. Clique "Nova Tarefa"
2. Título: "Rescisão João Silva"
3. Categoria: Rescisão
4. Prioridade: ALTA
5. Data: Hoje + 2 dias
6. Salvar → Aparece em "A Fazer"

### Exemplo 2: Folha Mensal
1. Criar tarefa "Folha Dezembro 2025"
2. Categoria: Folha de Pagamento
3. Prioridade: ALTA
4. Data: 05/01/2026
5. Mover para "Em Progresso"
6. Ao finalizar → "Concluído"

### Exemplo 3: Consulta FGTS
1. Tarefa "Verificar FGTS - Maria"
2. Categoria: Consultar Saldo FGTS
3. Prioridade: MÉDIA
4. Sem data urgente
5. Organizar quando tiver tempo
