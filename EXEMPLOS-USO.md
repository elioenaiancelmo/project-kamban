# 💼 Exemplos de Uso - Departamento Pessoal

## 🎯 Casos Práticos do Dia a Dia

### 1️⃣ Processar Rescisão de Contrato

**Situação**: Funcionário João Silva solicitou demissão

**Passo a Passo:**
```
1. Clique em "Nova Tarefa"
2. Título: "Rescisão Contratual - João Silva"
3. Descrição: "Demissão sem justa causa. Último dia: 15/12/2025"
4. Categoria: Rescisão
5. Prioridade: ALTA
6. Data de Vencimento: 15/12/2025
7. Salvar → Vai para "A Fazer"
```

**Acompanhamento:**
- Coluna "A Fazer": Aguardando processamento
- Arraste para "Em Progresso": Quando iniciar cálculos
- Arraste para "Concluído": Após homologação

**Dica**: Use descrição para anotar pendências (férias proporcionais, 13º, etc.)

---

### 2️⃣ Folha de Pagamento Mensal

```
4. Categoria: Folha de Pagamento
5. Prioridade: ALTA
6. Data de Vencimento: 05/01/2026
```

**Checklist na Descrição:**
```
☐ Lançar horas extras
☐ Processar faltas/atestados
☐ Calcular 13º salário
☐ Incluir bônus de final de ano
☐ Conferir descontos
☐ Gerar guias de pagamento
```

## 🏷️ Criar Categorias Personalizadas

### Exemplo: Adicionar categoria "Admissões"

```
1. Clique em "Nova Tarefa"
2. No campo Categoria, selecione "➕ Criar Nova Categoria"
3. Aparecerá um campo novo
4. Digite: "Admissões"
5. Preencha os demais campos da tarefa
6. Salvar

✅ Categoria "Admissões" criada!
Agora está disponível em todas as tarefas futuras
```

## 🎯 Organização por Prioridade

### 🔴 ALTA - Urgente/Legal
- Rescisões contratuais
- Folha de pagamento mensal
- Guias de recolhimento (vencimento próximo)
- Homologações
- Documentos para fiscalização

### 🟡 MÉDIA - Importante
- Recibos avulsos
- Consultas de débitos
- Programação de férias
- Atualizações cadastrais
- Relatórios mensais

### 🟢 BAIXA - Rotina
- Consultas FGTS
- Organização de arquivos
- Atualizações de sistema
- Solicitações não urgentes
- Melhorias processuais

## 📅 Gestão de Prazos

### Entendendo os Indicadores:

#### ✅ NO PRAZO (Verde)
```
Exemplo: Tarefa criada hoje para daqui 5 dias
Status: Tempo suficiente para executar
Ação: Trabalhe normalmente
```

#### ⚠️ EM ATRASO (Vermelho Piscante)
```
Exemplo: Tarefa com prazo ontem
Status: ATENÇÃO! Prioridade máxima
Ação: Execute imediatamente
```

#### ⚪ SEM PRAZO (Cinza)
```
Exemplo: Tarefa sem data definida
Status: Organize quando possível
Ação: Encaixe na rotina
```

#### ✔️ CONCLUÍDA (Verde)
```
Exemplo: Tarefa na coluna "Concluído"
Status: Finalizada com sucesso
Ação: Arquivar ou excluir
```

## 📊 Usar as Estatísticas

### Painel Lateral Direito:

```
┌─────────────────┐
│ Estatísticas    │
├─────────────────┤
│ 📊 Total: 15    │ ← Total de tarefas ativas
│ ✅ Concluídas: 3│ ← Tarefas finalizadas
│ ⏰ Pendentes: 12│ ← Tarefas em andamento
└─────────────────┘
```

**Interpretação:**
- **Total Alto**: Muitas demandas abertas
- **Concluídas Crescendo**: Boa produtividade
- **Pendentes Alto**: Necessita mais foco

## 💡 Dicas Profissionais

### 1. Rotina Matinal
```
8:00 - Abrir Kanban
8:05 - Verificar "Em Atraso" (prioridade máxima)
8:15 - Revisar "Em Progresso"
8:30 - Planejar tarefas do dia
```

### 2. Rotina Semanal
```
Segunda: Criar tarefas da semana
Quarta: Revisar progresso
Sexta: Mover concluídas / Limpar quadro
```

### 3. Boas Práticas
- ✅ Sempre defina datas de vencimento
- ✅ Use descrições detalhadas
- ✅ Atualize status constantemente
- ✅ Mova para "Concluído" ao finalizar
- ✅ Exclua tarefas antigas mensalmente

### 4. Emergências
```
Tarefa urgente chegou?
1. Criar tarefa imediatamente
2. Prioridade: ALTA
3. Data: Hoje ou amanhã
4. Adicionar à coluna "Em Progresso"
5. Notificar equipe se necessário
```
